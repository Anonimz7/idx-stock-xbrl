# NalarQuest (penempatan sementara)

Aplikasi kuis penalaran satu-file (bahasa Indonesia).

- `nalarquest.html` — aplikasi (buka langsung di browser; dataset dimuat dari JSON bila dijalankan via http, fallback ke data bawaan bila via `file://`)
- `nalarquest-dataset.json` — dataset soal terpisah (12 template + 4 soal statis)

Catatan: direktori ini hanya tempat penitipan sementara, bukan bagian dari
idx-stock-xbrl. Mode API backend di aplikasi nonaktif sampai backend disiapkan.
